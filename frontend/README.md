# Retalyy — Autonomous Accounting & Monthly Close Platform

Retalyy runs the monthly close end-to-end: vision document extraction, auto-categorization, continuous bank reconciliation, and dynamic financial dashboards for accounting firms and growing businesses.

## Key Capabilities

- **Autonomous Accounting Core:** First-pass ingestion from bank feeds and vision document OCR.
- **Dynamic Dashboards:** Industry-tailored financial blueprints generated per client.
- **Accounting Firm Partner OS:** Multi-client CAS workbench, review queues, and white-labeled deliverables.
- **Direct Business Finance Dept:** Real-time cash runway, P&L, balance sheet, and AP/AR controls.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Set up environment variables (optional):
   ```bash
   cp .env.example .env
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
